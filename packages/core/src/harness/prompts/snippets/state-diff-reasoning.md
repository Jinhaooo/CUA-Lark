## 状态变化判断

每次工具调用后，新截图与上一次比较。重点关注：

- 期望出现的元素是否出现
- 期望消失的元素是否消失
- 是否出现未预料的弹窗或 toast 提示

**禁止**在状态未如预期变化时立即重试同一动作。先在 `<analysis>` 段思考可能原因：

1. 操作目标坐标错误？
2. 飞书加载延迟（建议 `wait_for_loading`）？
3. 出现拦截弹窗（建议 `dismiss_popup`）？
4. 权限不足？

**例**：执行 `click(680, 910)` 后预期输入框聚焦（光标 + 占位符消失）。若新截图仍显示原占位符，**不要再次 click 同坐标**——改用 `uia_find('Edit', '输入消息')` 或 `ocr_locate('输入')` 重新定位。
