# 飞书 IM 通用工作流

任何针对"特定联系人或群组"的 IM 任务，都遵循三段式：

1. **定位会话**——左侧会话列表能直接看到目标会话标题，就点击进入；
   看不到，按 `Ctrl+K` 调出搜索框，输入名字关键词，从结果里选目标
2. **进入会话**——点会话项后，先截图看顶部聊天标题；
   不是目标 → 退到第 1 步重新选；是目标 → 进入第 3 步
3. **执行动作**——发文本：点底部输入框 → `type(text)` → `hotkey('Enter')`；
   撤回：右键最后一条消息 → 选"撤回"；其他动作类似

## 关键原则

- 判断"当前是哪个会话"的依据是**截图顶部聊天标题**，不是窗口标题、不是 url、不是其他 UI 元素
- 顶部标题与目标不一致时，**禁止直接打字**——先回到第 1 步切换会话
- 反复定位失败（搜不到 / 进了仍是错的会话）→ `call_user('找不到 X，请确认会话名是否正确')`，不要在错的会话里硬发
- 每次 `click` 切会话后，下一步必须 `screenshot` + 重读顶部标题，再决定是否打字
