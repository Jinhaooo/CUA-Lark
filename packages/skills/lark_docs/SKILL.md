# 飞书云文档通用工作流

云文档任务比 IM 复杂——入口在侧边栏，新建要走多级弹层，标题输入框是单独点出来的。
**禁止**跳步、**禁止**靠"猜"位置；每一步都先看截图确认元素到位再动手。

## 工具使用约束（demo 模式）

**本会话内禁止 `ocr_locate` / `ocr_read`**（慢且会匹配错位置）。需要在截图里定位元素：
- **首选肉眼判断坐标**——直接给 `click({x, y})`
- 拿不准用 `vlm_locate(prompt)`

## 新建空白文档（最常见任务）

完整动作序列共 **5 步**，一步对一轮迭代，**不要插入额外验证**：

1. **进云文档**——点左侧导航栏的"云文档"图标（飞书最左侧竖排第二/三个图标，看截图有"📄"或类似文档图样的那个）。点完截图确认右侧切到云文档主面板（看到"我的空间 / 共享空间 / 收藏 / 最近"等导航项）
2. **打开新建菜单**——点"新建"按钮（通常在云文档主面板左上角或顶部，蓝色 + 加号图标）。点完会弹出一个**类型选择浮层**（含"文档 / 表格 / 多维表格 / 思维笔记 / 文件夹 / 上传"等条目）
3. **选"文档"**——在弹出的浮层里点"文档"项。点完会弹**第二级浮层**：模板选择
4. **选"空白文档"**——在模板浮层里点"空白文档"（通常是第一个，没有任何样式预览的纯白色卡片）。**点完飞书自动跳到新文档的编辑页面，文档此刻已经创建好；标题/正文光标默认就位，不需要再去点标题占位符**
5. **直接 `type(<内容>)`**——光标默认聚焦在文档输入区（标题或正文，看截图哪边在闪）。任务给了标题就 type 标题；给了正文就 type 正文；标题正文都给了，先 type 标题 → `hotkey('Tab')` 跳到正文 → `type` 正文。**不需要先 click 任何位置**

## 关键原则

- **每次 click 后必须等下一轮迭代的截图回来**再决定下一步——飞书的浮层和新窗口都有几百毫秒重绘
- 如果点"新建"后没看到浮层，**不要重复点"新建"**（可能弹了又被遮挡），先 `screenshot` 确认整体状态
- 如果误点到了已有文档进了编辑态——按 `Esc` 或回到云文档主面板重来
- **文档创建完成的标志**：step 4 点完后跳转到的新页面就是已创建状态。看到文档编辑器（标题 + 正文区 + 工具栏）= 已建好，直接 type 即可
- 5 步全部走完才算任务完成

## 常见陷阱

- **"新建"按钮位置**：飞书 web/桌面客户端版本不同位置可能不一样；左上角找不到就看顶部工具栏右侧
- **多级浮层遮挡**：如果第二级浮层没出来，第一级可能还没消失；先 `screenshot` 看清当前在哪一层
- **不要先 click 标题占位符再 type**——飞书新文档的标题或正文已自动聚焦，多余的 click 等于多走 10-15 秒一轮 VLM
- **输入法**：中文 `type` 正常，但输入法候选词浮层可能拦截后续按键；type 完截图确认候选浮层已消失再做下一步

## 完成判据

- 文档窗口已打开，顶部显示用户指定的标题（不再是"无标题文档"）
- 正文区可见，光标在正文起始位置或仍在标题处
- 没有任何模态浮层遮挡

完成后立刻调 `finished({success: true, reason: "已创建标题为 X 的空白文档"})`，不要再多走一步。
