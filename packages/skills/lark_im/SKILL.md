# 飞书 IM 经验提示

下面是飞书 IM 操作的常见经验，**全部为建议性**——你判断任务是否适用，不适用就忽略。

## 任务边界（重要）

本 SKILL 只覆盖 IM 操作的局部经验。**进了对的会话 ≠ 必须在这个会话里完成任务**。

**当任务跨产品**（如 IM 看到日程卡片 → 切日历查看 / IM 收到文档链接 → 切云文档打开 / IM 读完信息 → 切其它面板继续），你**可以也应该**离开 IM 去做后续动作，不必死守"在 IM 域内完成"。需要时再调 `load_skill('lark_calendar')` / `load_skill('lark_docs')`（如目录里有），或直接用原子工具完成。

### 条件触发动作 = 先验证再回来执行

任务里出现"**如果 X 存在就做 Y**"、"**X 不存在才做 Z**"这种条件描述时，先离开当前会话去验证（切到日历 / 云文档 / 其它面板查），按任务条件方向再回来执行动作。

- 任务里的条件方向（"存在就..."vs"不存在才..."）逐字读，搞反 = 任务做错
- **验证完成 ≠ 任务完成**——除非任务只是"查一下"。验证后按条件回原会话执行后续动作或 finished，不能停在验证界面
- IM 卡片上的按钮（"加入日程"、"查看文档"、"接受"...）是**真正的动作触发器**——不要靠"在别处看到了同样的对象"就推断动作已完成；按钮还在 = 动作还没做

返回原会话的方式：左侧"消息"图标 → 点会话列表里的目标群；或 `Ctrl+K` 搜索后选。

## 定位元素

- **首选肉眼判断坐标**：你看到截图，直接 `click({x, y})`
- 拿不准时 `vlm_locate(prompt)` 让 VLM 给坐标
- OCR 工具（`ocr_locate` / `ocr_read`）单次 15-20 秒、且容易匹配到同名错位置（"发送给"会同时出现在群卡片、引用框、占位符里）。**默认不用**，仅当 VLM 也定位不到时再考虑

## 找会话 / 进会话

1. **定位**：左侧会话列表能看到目标 → 直接点；看不到 → `Ctrl+K` 搜索后选
2. **确认**：进入后**截图看顶部聊天标题**，标题对了再继续；不对就回到第 1 步重选
3. 反复找不到（搜不到 / 进错会话）→ `call_user('找不到 X，请确认会话名')`，不要硬猜

## 发文本消息

- 进入正确会话后**底部输入框通常已自动聚焦**——直接 `type(text)` → `hotkey('Enter')`，不需要先 click 输入框
- 仅当 `type` 后截图发现文字没出现（焦点被别的浮层抢了），才 `click` 输入框重聚焦
- 顶部标题与目标不符时**不要打字**

## 读消息 / 点消息卡片按钮

- 群里看到日程卡 / 文件卡 / 任务卡这类带按钮的卡片消息（"加入日程"、"查看文档"、"接受"等）→ **直接点卡片上的按钮**，不要走"切到该产品再搜索"的弯路
- 需要复制消息内容 → 右键消息 → "复制"
- 需要转发 → 右键消息 → "转发"

## 撤回

右键自己最后一条消息 → 选"撤回"

## 关键原则

- **判断会话**的唯一依据是截图顶部聊天标题，不是窗口标题、url 或其它 UI
- **每次 click 切会话后，下一步先 screenshot 再决定**（飞书会话切换有几百毫秒重绘）
- 上面所有规则都是"经验提示"——任务和经验冲突时听任务，不要为了"遵守 SKILL"绕远路
