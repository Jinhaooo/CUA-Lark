# 飞书日历经验提示

只是几条经验，不是流程。

- 飞书日历是独立面板，进入靠点**左侧主导航栏的"日历"图标**
- 判断某条日程是否在日历里：看时间网格里有没有那个日程块
- "**加入日程**"按钮在 **IM 群的日程卡片上**，不在日历里——任务需要"加入"时记得回 IM 操作
- 任务里"存在就 X / 不存在才 X"的条件方向逐字读，搞反 = 做错
